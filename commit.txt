[2026-11-03] - Remplacement de crypto.randomUUID par un generateur d'identifiant universel

What changed:
- frontend/src/components/ui.jsx :
  * 'crypto.randomUUID()' a ete remplace par une fonction generateur d'ID compatible tout contexte ('uid()').
  * Utilise 'crypto.randomUUID()' si disponible, sinon bascule sur un timestamp + sequenceur + aleatoire unique.

Why:
- 'crypto.randomUUID' n'est disponible dans les navigateurs que dans un 'Secure Context' (HTTPS ou localhost).
- Lorsqu'une application est accedee en simple HTTP sur une adresse IP directe, 'crypto.randomUUID' est 'undefined' et provoque une erreur 'TypeError: crypto.randomUUID is not a function' lors de l'affichage des notifications toast (ex. lors de la validation du profil).

Files affected:
- frontend/src/components/ui.jsx - Generateur d'ID compatible HTTP direct par IP
- commit.txt - Fiche descriptive du commit

Breaking changes:
- None.
