[2026-11-04] - Elimination definitive de crypto.randomUUID et polyfill HTTP natif

What changed:
- frontend/src/components/ui.jsx :
  * Remplacement complet de la fonction uid() par un generateur d'identifiant purement natif sans aucun appel a crypto.randomUUID.
- frontend/index.html :
  * Ajout d'un polyfill direct dans le <head> garantissant la disponibilite d'un generateur UUID standard meme en acces HTTP non chiffre sur IP.

Why:
- L'API window.crypto.randomUUID() est reservee par les navigateurs aux contextes securises (HTTPS ou localhost).
- Lors d'un acces direct en HTTP sur adresse IP sans certificat SSL, son invocation provoque l'erreur 'TypeError: crypto.randomUUID is not a function'.
- En supprimant toute reference dans le code et en injectant le polyfill en amont, l'erreur est definitivement neutralisee.

Files affected:
- frontend/index.html - Polyfill d'entree de page
- frontend/src/components/ui.jsx - Generateur d'identifiant universel
- commit.txt - Fiche descriptive du commit

Breaking changes:
- None.
