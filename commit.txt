[2026-11-03] - Epinglage cryptographique SHA-256 de toutes les images Docker de base

What changed:
- Securite de la supply chain logicielle (Supply Chain Security) :
  * Les tags d'images Docker etant mutables (un tag comme 'alpine' ou '16-alpine' peut etre modifie ou ecrase a tout moment par le registre), toutes les images ont ete figees sur leur empreinte cryptographique SHA-256 exacte (Digest pinning).
- Images epinglees :
  * PostgreSQL (docker-compose.yml) : postgres:16-alpine@sha256:721873c34ceb9f8d8fc265984940dc982404c105f19ad51be9fdc5970a6080ea
  * Backend Python (backend/Dockerfile) : python:3.12-slim-bookworm@sha256:e697c81897302a4c4333bade000d98038fbb21eb064f8ee1fd42d02ebcd9d337
  * Frontend Builder Node (frontend/Dockerfile) : node:20-alpine@sha256:fb4cd12c85ee03686f6af5362a0b0d56d50c58a04632e6c0fb8363f609372293
  * Frontend Serveur Nginx (frontend/Dockerfile) : nginx:alpine@sha256:785835ea65db4bba6f021acc0f3be91b0fef76a53fe41f8588c6698d2aed0606

Why:
- Garantir l'immutabilite absolue des environnements d'execution, empecher toute attaque par substitution de registre ou modification silencieuse d'image amont, et assurer une reproductibilite a 100% au bit pres.

Files affected:
- docker-compose.yml - Digest pinning postgres:16-alpine
- backend/Dockerfile - Digest pinning python:3.12-slim-bookworm
- frontend/Dockerfile - Digest pinning node:20-alpine et nginx:alpine

Breaking changes:
- None

Notes for review:
- Chaque build utilisera exactement ces memes binaires verifies.
