[2026-11-03] - Configuration du deploiement conteneurise Docker Compose et Nginx

What changed:
- Conteneurisation de la base de donnees et persistance des donnees (docker-compose.yml) :
  * Service 'db' utilisant postgres:16-alpine avec volume persistant nomme 'flux_postgres_data' (/var/lib/postgresql/data).
  * Les donnees restent intactes et preservees meme lors d'un 'docker compose down' ou reboot serveur.
  * Healthcheck automatique 'pg_isready' pour bloquer le demarrage du backend tant que PostgreSQL n'est pas pret.
- Conteneurisation de l'API Backend (backend/Dockerfile, backend/.dockerignore, backend/requirements.txt) :
  * Image minimale basee sur python:3.12-slim-bookworm.
  * Ajout de gunicorn==23.0.0 et httpx==0.28.1.
  * Execution securisee avec un utilisateur non-privilegie (appuser:appgroup).
  * Serveur de production Gunicorn avec 4 workers Uvicorn asynchrones (--bind 0.0.0.0:8000).
  * Liaison reseau stricte sur 127.0.0.1:8000 pour reserver l'acces exclusif au reverse proxy hote.
- Conteneurisation du Frontend (frontend/Dockerfile, frontend/nginx.conf, frontend/.dockerignore) :
  * Multi-stage build : compilation React avec node:20-alpine puis execution avec nginx:alpine.
  * Configuration Nginx dediee pour SPA (fallback try_files $uri /index.html).
  * Compression Gzip activee et mise en cache immutable des assets statiques hashés.
  * Liaison reseau stricte sur 127.0.0.1:3000.
- Modele de configuration Reverse Proxy hote (nginx-host.conf.example) :
  * Redirection automatique HTTP vers HTTPS.
  * Terminaison SSL avec en-tetes de securite stricts (HSTS, Anti-Sniff, Anti-Clickjacking).
  * Proxy pass /api/ vers http://127.0.0.1:8000 et /* vers http://127.0.0.1:3000.
  * Transmission propre des en-tetes X-Forwarded-For et X-Real-IP pour l'audit et le rate-limiting.
- Documentation (README.md) :
  * Ajout du guide de deploiement en production.

Why:
- Permettre un deploiement en production 100% conteneurise, reproductible, hautement disponible et securise, s'interfacant directement avec le Nginx existant de la machine hote sans conflit de ports ni exposition publique directe des conteneurs.

Files affected:
- docker-compose.yml - Orchestration des 3 services, volume persistant et reseau interne
- backend/Dockerfile - Image Docker de production pour l'API FastAPI / Gunicorn
- backend/.dockerignore - Exclusion des fichiers temporaires, caches et venv
- backend/requirements.txt - Ajout de gunicorn et httpx
- frontend/Dockerfile - Multi-stage build React + Nginx Alpine
- frontend/nginx.conf - Configuration serveur SPA et cache
- frontend/.dockerignore - Exclusion de node_modules et dist
- nginx-host.conf.example - Configuration reverse proxy Nginx pour le serveur hote
- README.md - Documentation du deploiement

Breaking changes:
- None

Notes for review:
