[2026-11-03] - Configuration Nginx hote HTTP port 80 pour acces direct par IP et support COOKIE_SECURE

What changed:
- Nginx Hote (nginx-host.conf.example) :
  * Simplification de la configuration pour un acces direct par IP sans nom de domaine ni SSL (HTTP port 80 avec server_name _).
  * Routage de /api/ vers 127.0.0.1:8000 et / vers le frontend conteneurise sur 127.0.0.1:3000.
  * Section HTTPS documentee et commentee pour activation ulterieure lors de l'obtention du nom de domaine et des certificats.
- Securite des sessions sur HTTP non chiffre :
  * Ajout du reglage 'cookie_secure' dans config.py et security.py pour eviter le blocage des cookies d'authentification sur une connexion HTTP directe par IP (attribut SameSite=Lax et Secure=False lorsque non HTTPS).

Why:
- Permettre un deploiement et des tests immediats sur le serveur distant en utilisant uniquement son adresse IP sur le port 80 standard, avant la mise en place du DNS et des certificats SSL.

Files affected:
- nginx-host.conf.example - Configuration HTTP port 80 sur IP directe
- backend/app/config.py - Ajout de la variable cookie_secure
- backend/app/security.py - Support flexible du flag Secure et SameSite pour cookies HTTP sur IP
- commit.txt - Fiche descriptive du commit

Breaking changes:
- None.

Notes for review:
- Si le serveur distant est accede en HTTP sur son IP avec ENVIRONMENT=prod, s'assurer que COOKIE_SECURE=false est defini dans backend/.env jusqu'a la mise en place de HTTPS.
